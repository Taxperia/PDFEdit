# Support

Start with the [README](README.md), particularly its usage instructions and limitations. This project is maintained on a best-effort basis; there is no paid support service or guaranteed response time.

## Bug reports

Use the [bug report form](https://github.com/Taxperia/PDFEdit/issues/new?template=bug_report.yml). Include reproducible steps, browser/OS, expected behavior, observed behavior and a sanitized screenshot or generated PDF if relevant. Explain whether the issue affects the preview, the exported PDF, or both.

Do not upload private documents or personal data. Check the console for useful error messages and redact paths, tokens and document contents before sharing logs.

## Feature requests

Use the [feature request form](https://github.com/Taxperia/PDFEdit/issues/new?template=feature_request.yml). Describe the problem and an example workflow. Check existing issues first.

## Security and privacy

Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Never disclose exploit details in public support requests. The eraser only covers content visually; it cannot safely remove confidential data from a PDF.
